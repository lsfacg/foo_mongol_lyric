# foo_mongol_lyric
foobar2000 传统蒙古文竖排歌词插件<br>
foobar2000 ᠮᠣᠩᠭᠣᠯ ᠬᠡᠯᠡᠨ ᠦ ᠳᠠᠭᠤᠤ ᠶᠢᠨ ᠦᠭᠡ ᠶᠢᠨ ᠨᠡᠮᠡᠯᠲᠡ<br>
foobar2000 Traditional Mongolian Vertical Lyrics Plugin<br>

1.插件支持竖排显示传统蒙古文及竖排中文翻译歌词<br>
2.支持更换字体（Windows 已安装的字体）<br>
3.支持自定义歌词文本及边框颜色<br>

注意事项：<br>
1.仅支持 Unicode 标准编码的传统蒙古文<br>
2.自动读取音频文件 ID3 标签内嵌 LYRICS 歌词，以及音频同路径下同名的 LRC 歌词文件<br>
3.插件暂不支持网络搜索，请自行准备内嵌歌词的音频文件 或 LRC歌词文件<br>
4.仅支持 x64<br>

歌词写法：<br>
[时间轴]蒙古文<br>
[时间轴]中文翻译<br>
例如：<br>
[00:00.00]ᠮᠣᠩᠭᠣᠯ ᠬᠡᠯᠡ<br>
[00:00.00]蒙古语<br>
[00:10.00]ᠦᠭᠡ<br>
[00:10.00]作词<br>
[00:15.00]ᠠᠶ᠎ᠠ<br>
[00:15.00]作曲<br>

安装方法：<br>
1.打开 foobar2000 “首选项”，单击“组件”，将 foo_mongol_lyric.fb2k-component 拖拽进窗口即可<br>
2.直接双击 foo_mongol_lyric.fb2k-component
