# foo_mongol_lyric
foobar2000 传统蒙古文竖排歌词插件<br>
foobar2000 ᠮᠣᠩᠭᠣᠯ ᠬᠡᠯᠡᠨ ᠦ ᠳᠠᠭᠤᠤ ᠶᠢᠨ ᠦᠭᠡ ᠶᠢᠨ ᠨᠡᠮᠡᠯᠲᠡ<br>
foobar2000 Traditional Mongolian Vertical Lyrics Plugin<br>

1.支持竖排显示传统蒙古文及竖排中文翻译歌词<br>
2.支持桌面歌词和内嵌窗口面板歌词<br>
3.支持拖动歌词音频跟随播放<br>
4.内嵌窗口面板歌词支持全屏<br>
5.歌词字体大小支持 “Ctrl” + 鼠标滚轮和触控放大手势进行调整<br>
6.支持更换字体（Windows 已安装的字体）<br>
7.支持自定义歌词文本及边框颜色、调整边框粗细<br>
8.支持置顶、锁定桌面歌词<br>
9.可选显示双语歌词、仅显示蒙古文、仅显示中文翻译<br>
10.可分开设置蒙古文、中文字体颜色及边框颜色<br>
11.支持 Unicode 标准编码及蒙科立编码的传统蒙古文<br>
12.默认使用 Unicode 标准编码字体，如需使用蒙科立编码请自行将字体更换为蒙科立字体<br>

注意事项：<br>
1.自动读取音频文件 ID3 标签内嵌 LYRICS 歌词，以及音频同路径下同名的 LRC 歌词文件<br>
2.插件暂不支持网络搜索，请自行准备内嵌歌词的音频文件 或 LRC歌词文件<br>
3.仅支持 x64<br>
4.暂不支持显示无时间轴的纯文本<br>

歌词写法：<br>
[时间轴]蒙古文<br>
[时间轴]中文翻译<br>
例如：<br>
[00:00.00]ᠮᠣᠩᠭᠣᠯ ᠬᠡᠯᠡ<br>
[00:00.00]蒙古语<br>
[00:10.00]ᠦᠭᠡ<br>
[00:10.00]作词<br>
[00:15.00]ᠠᠶ᠎ᠠ<br>
[00:15.00]作曲<br>

安装方法：<br>
1.打开 foobar2000 “首选项”，单击“组件”，将 foo_mongol_lyric.fb2k-component 拖拽进窗口即可<br>
2.或直接双击 foo_mongol_lyric.fb2k-component<br>

内嵌面板歌词添加方法：<br>
1.“视图/布局/启用布局编辑模式”，弹出窗口点击“确定”<br>
2.右键面板标题处，点击“新标签”<br>
3.右键新标签空白处，点击“添加新的用户界面组件”<br>
4.选择“蒙古文歌词”，点击“确定”<br>
5.“视图/布局”，取消勾选“启用布局编辑模式”
