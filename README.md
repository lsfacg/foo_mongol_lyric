# foo_mongol_lyric
foobar2000 传统蒙古文竖排歌词插件
foobar2000 ᠮᠣᠩᠭᠣᠯ ᠬᠡᠯᠡᠨ ᠦ ᠳᠠᠭᠤᠤ ᠶᠢᠨ ᠦᠭᠡ ᠶᠢᠨ ᠨᠡᠮᠡᠯᠲᠡ
foobar2000 Traditional Mongolian Vertical Lyrics Plugin

1.插件支持竖排显示传统蒙古文及竖排中文翻译歌词
2.支持更换字体（Windows 已安装的字体）
3.支持自定义歌词文本及边框颜色

注意事项：
1.仅支持 Unicode 标准编码的传统蒙古文
2.自动读取音频文件 ID3 标签内嵌 LYRICS 歌词，以及音频同路径下同名的 LRC 歌词文件
3.插件暂不支持网络搜索，请自行准备内嵌歌词的音频文件 或 LRC歌词文件
4.仅支持 x64

歌词写法：
[时间轴]蒙古文
[时间轴]中文翻译
例如：
[00:00.00]ᠮᠣᠩᠭᠣᠯ ᠬᠡᠯᠡ
[00:00.00]蒙古语
[00:10.00]ᠦᠭᠡ
[00:10.00]作词
[00:15.00]ᠠᠶ᠎ᠠ
[00:15.00]作曲

安装方法：
1.打开 foobar2000 “首选项”，单击“组件”，将 foo_mongol_lyric.fb2k-component 拖拽进窗口即可
2.直接双击 foo_mongol_lyric_1.0.1.fb2k-component
